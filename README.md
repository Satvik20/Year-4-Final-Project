# Athlone Flow 🚦

**A Java-Based Traffic Monitoring and Congestion Prediction System for Athlone, Ireland**

## 📌 Project Overview

Athlone Flow is a software engineering project focused on developing a prototype traffic monitoring system for Athlone, Ireland. The system aims to analyse traffic-related data, identify congestion levels and eventually provide short-term congestion predictions to help users better understand traffic conditions.

The project is being developed using an **Agile software development approach**, with an emphasis on iterative development, testing, version control and continuous improvement.

## 🎯 Project Objectives

- Develop a Java application for monitoring traffic conditions.
- Represent traffic information for selected roads in Athlone.
- Classify traffic congestion into Low, Moderate and High levels.
- Explore short-term congestion prediction using historical or sample traffic data.
- Investigate basic route comparisons based on traffic conditions.
- Apply Agile principles, GitHub version control and test-driven development where appropriate.
- Evaluate the feasibility of extending the prototype into a simplified traffic simulation or digital twin.

## 🚧 Planned Features

### Phase 1 — Core Traffic Monitoring
- Create a structured representation of traffic data.
- Display traffic information for selected roads.
- Implement basic congestion classification.
- Validate the classification logic using tests.

### Phase 2 — Congestion Prediction
- Investigate suitable historical or sample traffic datasets.
- Explore a basic method for predicting short-term congestion.
- Evaluate the results and document limitations.

### Phase 3 — Route Comparison
- Compare alternative routes using available traffic information.
- Explore how congestion levels could influence route selection.

### Future Extension — Traffic Simulation
- Investigate a simplified traffic simulation or digital twin, subject to time and feasibility.

## 📊 Data Sources

The project will investigate the availability and suitability of traffic data relevant to Athlone.

Where live or historical traffic data is unavailable, **clearly labelled simulated data** may be used to develop and test the prototype. Simulated data will not be presented as real-world traffic measurements.

Testing will be incorporated throughout development.

## ⚠️ Limitations

- Initial traffic information may be simulated rather than sourced from live traffic feeds.
- Congestion classifications will depend on the rules and data implemented.
- Prediction accuracy will depend on the availability and quality of suitable data.
- This is an academic prototype and is not intended for safety-critical or operational traffic-management decisions.
